# 新增模型实验：指标与区间复算

本目录包含2026-10-29新增图模型、Tanimoto核和训练预算实验的**已评价逐条预测**及可移植计算程序。它补充原公开包的Tables 1–5；两者的组数和统计范围分别记录。

## 快速运行

Python 3.10或以上，不需要PyTorch、RDKit、显卡、原始数据库或本机项目目录。整个目录可放在任意位置。

```bash
python replay.py --output reproduced-optimization
```

程序从28,000行逐条真值/预测重新计算MAE、R²、尾部误差和Top-K命中数，验证70个模型—seed组合、1,050项原始参考指标，然后输出逐seed表、五seed均值/样本标准差，以及图7的40行指标数据。不会仅复制论文表格。

重新计算48组共享结构簇条件区间时：

```bash
python -m pip install numpy
python replay.py --intervals --output reproduced-optimization
```

最后出现`"status": "PASS"`表示本次所选范围通过。完整区间复算应显示`metric_checks=1050`和`interval_checks=228`。失败会返回非零退出码；不要将旧输出目录中的PASS当作新运行结果。

## 输出文件

- `per_seed_metrics.csv`：70组，各自400条评价记录的指标、尾部样本数及K=10/20/50/100实际命中数。
- `summary_metrics.csv`：14种配置各五seed的均值和样本标准差（ddof=1）。
- `figure7_metrics.csv`：训练预算比较的40组结果。按模式、标签数和模型绘图；固定轮数与固定更新次数分别比较。
- `paired_cluster_intervals.csv`：加`--intervals`后生成，包含点差、95%区间、有效与空尾重采样次数。
- `verification.json`：本次范围、核对项数和结果。

## 数据与统计定义

1. 70组包括图消融20组、最终核模型10组、规模对照40组。同一原模型可能在不同实验中重复作为参照。28,000行来自1,738个不同record_id，不能当作28,000个独立聚合物。
2. 结构和数据来自PolyOmics固定版本`041e5834ea1a48682fae12dc39ccd723bcd4f771`，DOI：https://doi.org/10.57967/hf/7475 ，原始数据许可CC BY 4.0。这里保留原record_id、赋予的cluster_id、已评价热导率、模型预测和冻结训练阈值。做过子集选取和派生指标处理；软件许可不能替代源数据许可。请引用Hayashi等关于PolyOmics/RadonPy的原始工作。
3. MAE和R²按记录计算。尾区分别为对应训练q95、固定κ≥0.30和原600训练q95；不同标签预算自己的q95不能被误当同一评价群体。单位W/(m K)。
4. Precision@K定义为预测前K与真值前K集合交集大小除以K，稳定保存行序处理并列；它不是κ≥0.30阈值分类准确率。
5. 区间在已拟合模型固定条件下共享重采样评价结构簇，逐seed先算均值再平均五seed。任一seed尾部为空即整次剔除，报告有效/空尾次数。它不覆盖重新训练、模型选择或独立来源的不确定性。
6. 七单元上下文核是按指纹半径修正后的最终特征版本。早期五单元上下文不属于这次最终比较，完整历史仍保存在研究项目中。

## 运行含义

相同保存预测重新计算指标应相同，仅可能存在浮点舍入差异。本程序验证计算与论文新增结果相符，**不重新拟合模型、不重新推理，也不构成独立验证**。重新训练的波动和新输入预测是另外两类任务，不能用本程序的PASS代替。原始训练池、失败试验、未评价标签、论文全文和私人项目日志均不在此包内。
