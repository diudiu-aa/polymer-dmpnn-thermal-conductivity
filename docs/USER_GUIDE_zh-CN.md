# 本地预测工作台使用教程

这个界面调用仓库内已发布的论文模型权重，不需要写预测代码。
目标是约300 K、1 atm、未拉伸无定形体相聚合物的模拟热导率，单位W/(m·K)。

## 1. 下载和启动

先安装Python 3.10–3.13，建议3.12。然后在GitHub点击 **Code → Download ZIP**，解压整个仓库。
不要只保存一个启动脚本。Windows可双击`start_ui_windows.bat`；macOS可双击
`start_ui_macos.command`；Linux提供`start_ui_linux.sh`。
如果双击入口不能运行，在解压目录的终端执行：

```bash
python start_ui.py
# macOS可能需要：
python3 start_ui.py
```

首次启动自动在该仓库的`.ui-venv`建立专用环境，并通过pip安装模型和依赖，需要网络、
数分钟时间及数百MB以上空间；不修改系统Python包。之后复用同一个环境。
安装成功后自动打开本机浏览器；若未自动打开，复制终端中的`http://127.0.0.1:端口/`地址。
终端保持运行，按Ctrl+C关闭服务。输入和结果均留在本机，不需要API密钥。

已经手工安装依赖的研究者也可直接运行：

```bash
python -m pip install .
python -m polymer_dmpnn.web
# 只打印地址，不自动打开浏览器：
python -m polymer_dmpnn.web --no-browser --port 8765
```

仅安装wheel时仍能预测；五表复算需下载整个仓库，在其根目录启动，或通过
`--repository /你的/仓库目录`指定数据所在位置。

## 2. 单条结构预测

点击聚乙烯、聚丙烯或聚苯乙烯示例，或粘贴自己的重复单元SMILES，再点“开始预测”。
结构必须连通，恰好有两个以单键连接、各只有一个邻居的末端`*`。例如`*CC*`。
普通小分子`CC`没有聚合连接点，会显示具体错误，不能通过补一个标签变成聚合物输入。

右侧显示预测值、重复单元二维结构及所用模型标识。可下载CSV或JSON。
二维结构图只是输入重复单元的可视化，不是三维构象或热输运计算结果。

默认选中表5周期图模型、种子32101。双任务选项用于考察高值尾部取舍；其整体误差未必更小。
高级选项可选全部65个主要图模型以及旧三种子集成。相同输入、模型和环境下应获得相同预测；
切换模型或种子可能改变数值。一个种子的预测不等于论文五种子评价指标的平均值。
双任务分类头在完整JSON中返回原始logit，是排序分数，不是高导热概率。

## 3. 批量CSV与自己的参考值

切换“批量CSV”，上传UTF-8编码CSV，或展开粘贴框后点击“识别列名”。
先下载示例CSV作为模板。至少需要一列SMILES，列名可以自定义，并在“结构列”中选择。
`id`列可选，输出会保留该ID。最多1,000条记录、单条SMILES最多2,000字符，上传文件上限1.5 MB、整个请求最多2 MB；
更大的任务请分批或使用命令行。

如果有条件可比的真实热导率，可增加数值列，并在“参考热导率”中选中它。
下面只演示格式，**0.30和0.25是虚构的格式示例，不是实验或论文测量**：

```csv
id,smiles,kappa_reference
sample_a,*CC*,0.30
sample_b,*CCO*,0.25
```

输入结构错误的行保留在原位置，明确标为失败；其他可计算行继续。
参考值为空、非正数或非有限数时不纳入指标。界面显示有效配对数量、MAE、RMSE、R²。
R²需要至少两个参考值且参考值有变异，否则显示“—”；R²为负也是合法计算结果。
这些指标只描述你本次上传的配对数据，不自动成为论文的新验证结果。
参考值须用W/(m·K)，并自行确认温度、物态、取向、来源和模拟/实验差异，程序不自动换算单位。

下载CSV保留输入行号/ID、结构、预测、所用模型、参考值及错误信息；完整JSON还包含
模型输出、运行时间、软件版本和目标定义。表格软件可能隐藏小数，应查看原数值或JSON。
在表格下载中以`= + - @`开头的字符串会加前导单引号，防止被当作公式执行；数值列不受影响。

## 4. 点击复算论文表1–5

点击“开始五表复算”。程序从随包公开的预测与参考值重新计算182个显示统计，
与预期值核对。成功时显示182项、0不符，可下载含五张表、逐种子指标和核对记录的ZIP。
它不重新训练，不读取你的输入CSV，也不重新做原MD模拟。

“未找到复算数据”通常说明只下载了Python包、从其他文件夹启动，或缺少`reproduce/`目录。
请下载完整仓库或使用`--repository`。修改过公开数据而核对失败时，程序不会伪装成通过。

## 5. 常见问题

- **python不存在**：先安装Python并确认命令可用；Windows安装时选择加入PATH，macOS通常使用`python3`。
- **依赖下载失败**：保留终端具体报错，检查网络和磁盘空间后重试同一启动命令。不要反复创建仓库副本。
- **双击文件不能执行**：使用Python命令启动，无须关闭系统安全保护。
- **浏览器连不上**：确认终端仍运行，使用它本次打印的地址；默认端口每次可能不同。
- **结构失败**：按该行错误修正两个末端连接点、连通性和SMILES语法。
- **RDKit版本提醒**：仓库允许支持范围内的版本，提醒本身不代表失败。数值差异须结合模型身份和软件版本排查。
- **为什么不能保证陌生材料都准**：成功推理只说明完成计算；适用域、模拟条件和训练分布决定误差，需条件匹配的参考数据检验。

反馈问题时请附Git提交号、Python版本、模型ID、操作步骤、可公开的最小输入和报错。
不要上传保密数据。环境元信息可从“下载完整JSON”取得。
