# 本地训练、测试与预测工作台

默认入口是**按论文原设置运行主结果**：别人下载代码和数据后，自己训练出新模型，再看是否达到相近水平以及结果如何波动。
目标仍是约300K、1atm未拉伸无定形体相的MD参考热导率，不是新实验测量。

## 1. 下载和启动

先安装Python 3.10–3.13，建议3.12。然后在GitHub点击 **Code → Download ZIP**，解压整个仓库。
不要只保存一个启动脚本。Windows可双击`start_ui_windows.bat`；macOS可双击
`start_ui_macos.command`；Linux提供`start_ui_linux.sh`。
如果双击入口不能运行，在解压目录的终端执行：

```bash
python start_ui.py
# macOS可能需要：
python3 start_ui.py
```

首次启动自动在该仓库的`.ui-venv`建立专用环境，并通过pip安装模型和依赖，需要网络、
数分钟时间及数百MB以上空间；不修改系统Python包。之后复用同一个环境。
安装成功后自动打开本机浏览器；若未自动打开，复制终端中的`http://127.0.0.1:端口/`地址。
终端保持运行，按Ctrl+C关闭服务。输入和结果均留在本机，不需要API密钥。

已经手工安装依赖的研究者也可直接运行：

```bash
python -m pip install .
python -m polymer_dmpnn.web
# 只打印地址，不自动打开浏览器：
python -m polymer_dmpnn.web --no-browser --port 8765
```

仅安装wheel时仍能预测；五表复算需下载整个仓库，在其根目录启动，或通过
`--repository /你的/仓库目录`指定数据所在位置。

## 2. 默认：运行论文主结果

保持默认“按论文原设置运行：生成主结果表”，点击“运行论文主结果”。
程序按原5组划分、原5组训练随机设置和冻结参数，从头训练15个核心模型，
完成后用本次新预测生成paper_main_results.csv并核对34个论文显示数值。
点击“下载论文主结果表CSV”即可查看对应主结果，不需要重新做数据收集或MD模拟。

范围是表5开链、周期、双任务及分类排序；不把这一入口称为整篇历史研究全部重建。
如果不同环境有差异，页面和paper_consistency.json会保留差异记录，不改结果凑一致。
原始材料标签与发布权重均不覆盖。

```bash
python reproduce/train_from_scratch.py --paper-settings --output paper-main-results
```

## 可选：新随机起点试跑

以下随机试跑用于观察波动，现已移为可选项；不用于要求论文数值一致的主流程。

### 随机试跑的设置

启动后保持默认“从头训练并测试”，选择：

- **配对试跑**：固定论文第1组训练/评价数据，开链、周期、双任务各训练一个新模型，共3次拟合。
- **完整重复**：在原5组固定数据划分上分别训练三个模型，共15次拟合，计算均值和样本标准差。

点“从头训练，再测试”。每个模型按原配方训练50轮、batch16、Adam和原学习率调度，
每组使用600条拟合标签和400条评价记录；评价数据不用于训练梯度、调参或提前停止。
初始化、样本顺序与dropout采用本次新随机起点，同组的三个模型共享该起点以便配对。
原始材料标签、物态、数据角色和超参数不变；不加载已发布.pt权重。

页面显示真实训练轮次、累计优化步数和各模型训练曲线。各模型目标函数不同，不直接用训练loss高低给模型排名。
完成后看MAE/R²、尾部MAE和候选命中率的新旧对照、实际预测散点、候选排名变化。

单组试跑只能与同一组划分的原成绩比较，不是论文五次平均，也没有可估计的重复标准差。
完整5组才计算样本标准差（不是置信区间）。成绩可以变好或变差，程序不因表现不好自动重训或挑选最好结果。
参考评价集已用于原公开研究，仍属于复现/稳定性试跑，不是新的独立盲测。

下载ZIP包含新weights.pt、逐条新预测、训练曲线、配置/训练起点、身份指纹及日志。
CLI可按记录的起点重跑，同环境下也可能重新得到完全相同结果；不要为了变化改原始标签或人为加噪声。

```bash
python reproduce/train_from_scratch.py --repeats 1 --output new-training
python reproduce/train_from_scratch.py --repeats 1 --training-seed 123456 --output replay-training
```

输出目录必须是新目录。--repeats 5运行完整重复；不改变原划分。已发布精确原配置仍可用
train_graph_models.py原命令，新增--training-seed只改训练随机性，--seed继续指定原数据划分。

训练中可停止，最长30分钟；只保留最近一次临时训练，请下载后再开始下一次，关闭服务会清理临时文件。
训练和旧权重批量重测不能并行启动。新模型不会覆盖论文权重、原数据或主稿结果。

## 3. 单条结构预测

第一次使用先点击页面上方“一键体验：聚乙烯”，会自动选好默认模型并显示结果。
之后可点击聚乙烯、聚丙烯或聚苯乙烯示例，或粘贴自己的重复单元SMILES，再点“开始预测”。
结构必须连通，恰好有两个以单键连接、各只有一个邻居的末端`*`。例如`*CC*`。
普通小分子`CC`没有聚合连接点，会显示具体错误，不能通过补一个标签变成聚合物输入。

右侧显示预测值、重复单元二维结构及所用模型标识。可下载CSV或JSON。
二维结构图只是输入重复单元的可视化，不是三维构象或热输运计算结果。

默认选中“周期图 D-MPNN”（表5周期模型，训练版本1，原始种子32101）。
普通使用无需选择数字；高级选项中的重复训练版本1–5对应原始随机种子32101–32105，
是同一算法从不同随机起点训练的5份权重，不是材料属性。模型原始标识保留在结果的“计算记录”和下载文件中。双任务选项用于考察高值尾部取舍；其整体误差未必更小。
高级选项可选全部65个主要图模型以及旧三种子集成。相同输入、模型和环境下应获得相同预测；
切换模型或种子可能改变数值。一个种子的预测不等于论文五种子评价指标的平均值。
双任务分类头在完整JSON中返回原始logit，是排序分数，不是高导热概率。

## 4. 批量CSV与自己的参考值

切换“批量CSV”，上传UTF-8编码CSV，或展开粘贴框后点击“识别列名”。
先下载示例CSV作为模板。至少需要一列SMILES，列名可以自定义，并在“结构列”中选择。
`id`列可选，输出会保留该ID。最多1,000条记录、单条SMILES最多2,000字符，上传文件上限1.5 MB、整个请求最多2 MB；
更大的任务请分批或使用命令行。

如果有条件可比的真实热导率，可增加数值列，并在“参考热导率”中选中它。
下面只演示格式，**0.30和0.25是虚构的格式示例，不是实验或论文测量**：

```csv
id,smiles,kappa_reference
sample_a,*CC*,0.30
sample_b,*CCO*,0.25
```

输入结构错误的行保留在原位置，明确标为失败；其他可计算行继续。
参考值为空、非正数或非有限数时不纳入指标。界面显示有效配对数量、MAE、RMSE、R²。
R²需要至少两个参考值且参考值有变异，否则显示“—”；R²为负也是合法计算结果。
这些指标只描述你本次上传的配对数据，不自动成为论文的新验证结果。
参考值须用W/(m·K)，并自行确认温度、物态、取向、来源和模拟/实验差异，程序不自动换算单位。

下载CSV保留输入行号/ID、结构、预测、所用模型、参考值及错误信息；完整JSON还包含
模型输出、运行时间、软件版本和目标定义。表格软件可能隐藏小数，应查看原数值或JSON。
在表格下载中以`= + - @`开头的字符串会加前导单引号，防止被当作公式执行；数值列不受影响。

## 5. 检查已发布模型（其他核对菜单）

打开“其他核对”里的 **“检查已发布模型”**，再点 **“开始重新测试 · 15组模型”**。
这个按钮实际让开链、周期、双任务模型各5份已发布权重重新预测固定评价集，
每组400条，共6000次预测（包含跨模型/重复训练版本的同一材料）。

新预测全部生成并保存后，程序才读取以前保存的预测作比较。随后用本次预测重新计算
MAE、R²、尾部MAE、Precision@10/100和材料排名，显示：

- 真实计算进度、当前模型、运行编号、开始时间和耗时。
- 原论文/本次结果的配对图、数值差值及预测一致性散点图。
- 逐条预测容差核对、原论文显示小数核对和前100候选集合一致性，三者分开报告。
- 新预测、材料排序、环境/输入/权重身份和运行日志的ZIP下载。

每点一次开始（上次已结束时），都会生成新运行和新预测；计算过程中重复点击不会启动第二份任务。
计算时可点击停止；单次最多10分钟，超时停止并保留日志。为节省空间，仅保留最近一次临时运行，
请先下载再开始下一次；关闭服务会清理临时文件。

这是固定权重重新测试，不重新训练、不重新运行MD。默认覆盖表5三个主线模型及双任务分类排序，
本次34个显示数值不是全论文182项重新训练。原表1–4、平衡采样及传统基线未包含于本按钮。
散点图展示固定抽样至多501点（包含最大差异点），逐条核对覆盖全部6000次预测。

如果希望从命令行运行相同的真实重测：

```bash
python reproduce/retest_models.py --output fresh-model-retest
```

输出目录须为新目录。不需要自己准备原作者的私人文件。

## 6. 核对已保存数值（较快的统计复算）

打开“其他核对”里的 **“核对保存数值”**。程序自动读取随仓库公开的输入，重新计算并核对论文表1–5，
无须上传文件。核对通过后，网页直接显示：

- 一致统计数、不一致项数、预测组数和评价行数；评价行包含跨模型/种子重复，不是独立聚合物数。
- 五张表的切换按钮，以及每张表的完整复算数值（均值±样本标准差）。
- 模型比较条形图，可切换MAE、R²、尾部误差和筛选命中率；表1/2按标签预算分开看。
- 表4的学习曲线，比较实际拟合标签数60、180、600、1800下的开链/周期模型（横轴为对数刻度）。
- 全部五表ZIP、当前CSV、当前SVG图及核验JSON的下载按钮。

图表直接使用本次重新计算生成的CSV显示值绘制，不写死结果；线段是样本标准差，不是置信区间。
MAE和尾部MAE越低越好，R²和命中率越高越好。“—”代表没有该项结果，不当成0画图。
切换表会保持各自原来的数据划分与统计口径，不能把不同表当成同一测试集。

这一步从保存预测重算指标，不重新训练、不重新运行原MD，也不使用你在预测区上传的CSV。
“未找到复算数据”通常说明没有下载完整仓库、从其他目录启动或缺少`reproduce/`目录。
请下载完整仓库或用`--repository`指定。核对失败时网页会显示失败，不展示为成功。

## 7. 常见问题

- **python不存在**：先安装Python并确认命令可用；Windows安装时选择加入PATH，macOS通常使用`python3`。
- **依赖下载失败**：保留终端具体报错，检查网络和磁盘空间后重试同一启动命令。不要反复创建仓库副本。
- **双击文件不能执行**：使用Python命令启动，无须关闭系统安全保护。
- **浏览器连不上**：确认终端仍运行，使用它本次打印的地址；默认端口每次可能不同。
- **结构失败**：按该行错误修正两个末端连接点、连通性和SMILES语法。
- **RDKit版本提醒**：仓库允许支持范围内的版本，提醒本身不代表失败。数值差异须结合模型身份和软件版本排查。
- **为什么不能保证陌生材料都准**：成功推理只说明完成计算；适用域、模拟条件和训练分布决定误差，需条件匹配的参考数据检验。

反馈问题时请附Git提交号、Python版本、模型ID、操作步骤、可公开的最小输入和报错。
不要上传保密数据。环境元信息可从“下载完整JSON”取得。
